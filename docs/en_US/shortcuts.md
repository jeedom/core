# Jeedom V4 - Keyboard and Mouse Shortcuts

### General

When you open a page (Dashboard, Scenarios, etc.), the focus is on the search field. This means you can start typing a search query right away without having to do any other action.

- Click the clock (menu bar): Opens the Timeline.
- Click on the Jeedom name (menu bar): Opens **Settings → System → Configuration**.
- Click the ?  (menu bar)  : Opens the help for the current page.
- Press Esc in a search field: Clears the search field and cancels the search.

### Dashboard
In edit mode:
	- Drag and drop the tiles to rearrange them.
	- Click on the tile borders to resize them.
	- Context menu (right-click) on the tiles.
	- Ctrl-click on an *expand* icon: Adjusts the height of the object's tiles not relative to the tallest one, but relative to the shortest one.

- Ctrl-click on a command to view info: Opens all historical data for the tile in the history window.

### Settings / System / Configuration
- Ctrl+S: Save.

### Settings / System / Backups
- Ctrl+S: Save.

### Settings / System / Task Engine
- Ctrl+S: Save.

### Settings / System / Users
- Ctrl+S: Save.

### Settings / Preferences
- Ctrl+S: Save.

### Tools / Interactions
- During an interaction, Ctrl+S: Save.
- In an interaction, right-click on a tab: A context menu appears, allowing you to go directly to another interaction.
- Ctrl-click or middle-click on an interaction or in the context menu: Opens the interaction in a new browser tab.

### Tools / Objects
- On an object, Ctrl+S: Save.
- On an object, right-click a tab: Context menu to go directly to another object.
- Ctrl-click or middle-click on an object or in the context menu: Opens the object in a new browser tab.

### Tools / Widgets
- On a widget, Ctrl+S: Save.
- On a widget, right-click a tab: A context menu will appear, allowing you to go directly to another widget.
- Ctrl-click or middle-click on a widget or in the context menu: Opens the widget in a new browser tab.

### Tools / Scenarios
- Ctrl-click or middle-click on a scenario or in the context menu: Opens the scenario in a new browser tab.

In a scenario:
- Ctrl+S: Save.
- Right-click on a tab: Context menu to go directly to another scenario.
- Ctrl+L: View log.
- Ctrl+Shift+Z: Undo.
- Ctrl Shift Y: Redo.

- Ctrl-click on Run: Saves and runs the scenario, then opens the log.
- Ctrl-click the *Copy this block* icon: Cut this block.
- Control-click the *Paste a block* icon: Replace this block.
- Ctrl-click the *Delete this block* icon: Delete the block without confirmation.
- Ctrl-click the *Hide this block* icon: Hides or shows all blocks.

In a code block:
- Ctrl+F: Search the code.
- Ctrl+G: Next occurrence of the search term.

### Plugins / Plugin Management
- Press Ctrl+S on a plugin configuration: Save.
- Ctrl-click or middle-click on a plugin: Opens the plugin settings in a new browser tab.

### Plugins / *plugin*
- On a device, Ctrl+S: Save.
- On a device, right-click a tab: Context menu to go directly to another device.
- Ctrl-click or middle-click on a device: Opens the plugin's device page in a new browser tab.

### Home / View
- Press Ctrl+S while editing a view: Save.

### Home / Design
- Press Ctrl+S on a design: Save.
- Ctrl+Shift+E on a design: Toggle edit mode on or off.

### Analysis / Summary of Home Automation
- Ctrl-click the *Open* icon (search): Opens all objects and all devices.
- Ctrl-click the *Close* icon (search): Closes all objects and all devices.

### Analysis / History
If multiple graphs are displayed:
- Ctrl-click on a legend: Show only this history.
- Alt-click on a legend: Show all history data.

### History Window
If multiple graphs are displayed:
- Ctrl-click on a legend: Show only this history.
- Alt-click on a legend: Show all history data.

### Equipment Configuration Window
- Ctrl-click "Save": Saves and closes the window.

### Command Configuration Window
- Ctrl-click "Save": Saves and closes the window.
