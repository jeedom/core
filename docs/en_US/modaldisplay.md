# ModalDisplay

The **ModalDisplay** page is a simple container used to load the contents of a window (*modal* or *dialog*) in full-page mode.

It is used in the following situations, among others:
- Analysis Menu: Ctrl-Click / Middle-Click on *Real-Time*
- Tools Menu: Ctrl-Click / Middle-Click on *Notes*, *Expression Tester*, *Variables*

> With a normal click (left-click), these menus open a window that displays the content on top of the rest of the interface. Here, the window's content is displayed on this page, which loads in a new browser tab, making it easier for the user to access whenever they want.
