# Search
**Analysis Menu → Search**

Jeedom offers an internal search engine.

![Search](../images/search_intro.gif)

You can perform different types of searches:

## By Equipment

Select a device using the icon to the right of the field.

The engine will display the following in the tables below:

- **Scenarios** that use this equipment.
- **Designs** featuring this equipment.
- The **views** displaying this equipment.
- **Interactions** using this equipment.
- Other **devices** that use this device.
- The **commands** that use this equipment.

## By Command

Select a command using the icon to the right of the field.

The engine will display the following in the tables below:

- The **scenarios** that use this command.
- **Designs** that include this command.
- The **views** that display this command.
- **Interactions** that use this command.
- The **devices** that use this command.
- Other **commands** that use this command.

## By Variable

Select a variable from the drop-down list.

The engine will display the following in the tables below:

- The **scenarios** that use this variable.
- **Interactions** that use this variable.
- The **devices** that use this variable.
- The **commands** that use this variable.

## By Plugin

Select a plugin from the drop-down list.

The engine will display the following in the tables below:

- The **scenarios** that use this plugin.
- **Designs** that display this plugin.
- The **views** displaying this plugin.
- **Interactions** that use this plugin.
- The **devices** that use this plugin.
- The **commands** that use this plugin.

## By Mot

Enter a string of characters in the search field. Press *Enter* or click the *Search* button.

The engine will display the following in the tables below:

- The **scenarios** that use this chain.
Search within expressions, comments, and code blocks.
- **Interactions** that use this channel.
Search in the *Request* fields.
- The **devices** that use this channel.
Search in the *name*, *logicalId*, *eqType*, *comment*, and *tags* fields.
- The **commands** that use this string.
Search in the *name*, *logicalId*, *eqType*, *generic_type* fields.
- **Notes** that use this string.
Search within the text of the notes.

## By ID

Enter a number corresponding to the ID you are looking for in the search field. Press *Enter* or click the *Search* button to confirm.

The engine will display the following in the tables below:

- The **scenario** with this ID.
- The **design** with this ID.
- The **view** with this ID.
- The **interaction** with this ID.
- The **device** with this ID.
- The **command** with this ID.
- The **note** with this ID.

## Results

For each type of result, it allows for the following actions:
- **scenarios**: Open the scenario log, or go to the scenario page, with the search active for the search term.
- **designs**: View the design.
- **views**: Display the view.
- **Interactions**: Open the interaction configuration page.
- **Device**: Open the device's configuration page.
- **Commands**: Open the command configuration.
- **Notes**: Open the Note.

Each of these options opens a new tab in your browser so you don't lose your current search.
