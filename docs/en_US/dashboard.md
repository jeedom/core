# Dashboard
**Home → Dashboard**

<small>[Keyboard/Mouse Shortcuts](shortcuts.md)</small>

The dashboard is one of Jeedom's main pages; it displays an overview of your entire home automation system.
This report (unlike views and designs) is automatically generated by Jeedom and includes all visible objects and their devices.

{% include lightbox.html src="../images/doc-dashboard-legends.png" data="Dashboard" title="Dashboard" imgstyle="width:450px;display: block;margin: 0 auto;" %}

- 1: Jeedom main menu.
- 2: Overall Summary [Documentation on summaries.](https://doc.jeedom.com/concept/en_US/summary).
- 3: Browser time, shortcut to the Timeline.
- 4: Button to access the documentation for the current page.
- 5: Name of your Jeedom, shortcut to the configuration.
- 6: Mode édition (Reorder/resize tiles).
- 7: Filter by category.
- 8: Object: Icon, name, and summaries, and its devices.
- 9: Equipment tile.
- 10: Command widget.

> **Tip**
>
> The order in which objects appear on the Dashboard is the same as the order shown in **Analysis → Home Automation Summary**. On this page, you can reorder the objects using drag-and-drop.

For a device to appear on the Dashboard, it must:
- Stay active.
- Be visible.
- Have a parent object that is visible on the Dashboard.

When a device first appears on the Dashboard, Jeedom attempts to resize its tile appropriately to display all commands and their widgets.
To keep your Dashboard balanced, you can switch to Edit mode by clicking the pencil icon in the upper-right corner of the search bar to resize and/or reorder the device tiles.

When you hover your mouse over a command, a colored marker appears in the lower-left corner of the tile:
- Blue for an information command. If it has been logged, clicking on it opens the history window.
- Orange indicates an action command. One click will trigger the action.

In addition, you can click on the tile's title (the device name) to go directly to that device's configuration page.

> **Tip**
>
> You can go directly to a specific object in your home automation system via the **Home → Dashboard → Object Name** menu.
> This allows you to see only the devices you're interested in and helps the page load faster.

- In the upper-left corner, there is a small icon that displays the object tree when you hover over it.
- A search field allows you to search for a device by its name, category, plugin, tag, etc.
- The icon to the right of the search field lets you filter the devices displayed by category. Clicking the center of the icon allows you to quickly select a single category.
- On the far right, a button lets you switch to edit mode to change the order of the tiles (click and drag on the widget) or resize them. You can also reorder the commands within a tile.

- When you click on an object summary, you filter the results to display only the devices that are children of that object and that are related to that object summary.

- Clicking on an information-type command displays the command history (if it is logged).
- Pressing Ctrl+Click on a "information" type command displays the history of all commands (logged) for that tile.
- Clicking on the *time* field of an action command displays the command's history (if it has been logged).

## Mode édition

In edit mode (*the pencil icon in the upper-right corner*), you can change the size of the tiles and their layout on the Dashboard.

The refresh icons for devices are replaced by an icon that allows you to access their settings. This icon opens an editing window containing the display settings for the device and its commands.

![Mode édition](../images/EditDashboardModal.gif)

For each object, to the right of its name and summaries, two icons allow you to align the height of all the object's tiles with the tallest or shortest one.

## Jeedom menu bar

> **Tip**
>
> - Click the clock (menu bar): Opens the Timeline.
> - Click the Jeedom name (menu bar): Opens Settings → System → Configuration.
> - Click the ? (menu bar): Opens the help for the current page.
> - Press Esc on a search field: Clears the field and cancels the search.
