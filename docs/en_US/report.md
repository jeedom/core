# Report
**Analysis → Report**

This page displays all reports generated by the "report" action (see the scenario documentation).

## Principle

A report is a screenshot of the Jeedom interface at a given moment.

> **Note**
>
> This screenshot is cropped to exclude the menu bar and other unnecessary elements for this type of use.

You can do this on views, designs, dashboard pages, etc.

Generation is triggered by a scenario using the "report" command.
You can choose to have this report sent to you via a messaging command (email, Telegram, etc.).

## Usage

It's very easy to use. On the left, select what you want to view:

- View reports.
- Design reports.
- Plugin panel reports.
- Equipment reports (to view a summary of each module's battery status).

Next, select the name of the report in question. You will then see all the available report dates.

> **Important**
>
> Reports older than 30 days are automatically deleted by default. You can configure this time limit in the Jeedom settings.

Once you've selected the report, you can view it, download it, or delete it.

You can also delete all backups of a specific report

## FAQ

> If you encounter an error of the type "Details:
> *cutycapt: error while loading shared libraries: libEGL.so: cannot open shared object file: No such file or directory*
> You must do the following via SSH or in Settings → System → Configuration: OS/DB / System Administration:
> ```sudo ln -s /usr/lib/aarch64-linux-gnu/libGLESv2.so.2 /usr/lib/aarch64-linux-gnu/libGLESv2.so```
> ```sudo ln -s /usr/lib/aarch64-linux-gnu/libEGL.so.1 /usr/lib/aarch64-linux-gnu/libEGL.so```
