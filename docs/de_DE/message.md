# Nachrichtenzentrum
**Menüleiste**

Das Nachrichtencenter fasst alle wichtigen Nachrichten zusammen, die Sie lesen sollten. Es befindet sich links neben der Uhrzeit und rechts neben der Jeedom-Menüleiste.

Es ist nur zugänglich, wenn Nachrichten vorliegen; dazu klicken Sie auf die Anzahl der Nachrichten.

Es ist ganz einfach. Es zeigt Ihnen das Datum und die Uhrzeit der Meldung, das Plugin, das sie ausgelöst hat, sowie die betreffende Meldung an. Durch Antippen der Schaltfläche ganz am Anfang der Zeile einer Meldung können Sie die betreffende Meldung löschen (sie erscheint wieder, falls das Problem weiterhin besteht).

Oben befindet sich ein Auswahlfeld, mit dem man die Nachrichten nach einem bestimmten Plugin filtern kann, und ganz rechts eine Schaltfläche, um alle Nachrichten zu löschen.

> **Tipp**
>
> Wenn im Nachrichtencenter ein Fehler auftritt, versuchen Sie zunächst, die Nachricht zu löschen, und prüfen Sie dann, ob der Fehler erneut auftritt, bevor Sie sich an den Support wenden. Manchmal liegt das Problem lediglich an einer gestörten Netzwerkverbindung.
