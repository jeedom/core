# Jeedom-Marktplatz


Ein etwas ungewöhnliches Dokument, da es sich ausschließlich mit Ihrer Profilseite im Market befasst.
Verfügbar, indem Sie im Market auf Ihren Benutzernamen und dann auf „Profil“ klicken (ähnlich wie bei Jeedom).

Diese gliedert sich in mehrere Bereiche:

## Mein Profil

Hier können Sie verschiedene Einstellungen in Ihrem Profil anpassen:

- **Profil**
    - **Login**: Ihr Login für den Market kann nicht geändert werden.
    - **Name**: Ihr Name (diese Angabe dient lediglich dazu, E-Mails persönlicher zu gestalten).
    - **Vorname**: Ihr Vorname (diese Angabe dient lediglich dazu, E-Mails persönlicher zu gestalten).
    - **Benutzername im Forum**: Ihr Benutzername im Forum.
    - **E-Mail**: Ihre E-Mail-Adresse.
    - **Sprache**: Ihre Sprache.
    - **Passwort && Passwort bestätigen**: Hier können Sie Ihr Passwort ändern.

Für Entwickler:
- **Benutzername im Forum**: Ihr Benutzername im Forum.
- **Öffentliche E-Mail-Adresse**: Ihre E-Mail-Adresse, an die wir Ihnen gegebenenfalls Mitteilungen senden können.
- **PayPal-Konto**: Ihre E-Mail-Adresse für Ihr PayPal-Konto (wird ausschließlich zur Bezahlung der Entwickler verwendet).

Für Fachleute:
- **E-Mail-Konto des Installateurs**: Ihre geschäftliche E-Mail-Adresse.
- **Empfänger von Supportanfragen**: Legen Sie fest, wer die Support-E-Mails erhält (Endkunde, Installateur oder beide).
    - **Nutzungsbedingungen**
- **Nutzer**: Allgemeine Nutzungsbedingungen (bitte lesen Sie diese sorgfältig durch, da sie für Sie verbindlich sind).
- **Entwickler**: Allgemeine Nutzungsbedingungen für Entwickler.
    - **Tickets**
- **Anzahl der Tickets**: Anzahl der Tickets für den laufenden Monat sowie Ihr Limit.
- **Support**: Schaltfläche zum Senden einer Supportanfrage (auch über das Ausrufezeichen oben rechts im Market oder in Ihrem Jeedom erreichbar).
    - **Zugang zu den Beta-Versionen**
- **Zugriff auf Beta-Plugins aktivieren**: Ermöglicht den Zugriff auf Beta-Plugins (Achtung: Dadurch wird Ihnen jeglicher Zugang zum Support verwehrt).
    - **Zusammenfassung** Hier finden Sie eine Zusammenfassung Ihrer verschiedenen Rechte und Dienstleistungen.

> **Tipp**
>
> Vergessen Sie nicht, zu speichern.

## Meine Jeedoms

- **Niveau**
    - **Jeedom**: Ihr Service-Pack-Level.
    - **Service-Pack-Nummer eingeben**: Hier können Sie Ihre Service-Pack-Nummer eingeben (diese finden Sie in der E-Mail, die Jeedom Ihnen bei Ihrer Bestellung gesendet hat).
- **Installationsschlüssel**
    - **Anzahl der Installationsschlüssel**: Zeigt die Anzahl der derzeit mit Ihrem Konto verknüpften Jeedom-Installationen sowie das zulässige Limit an.

> **Tipp**
>
> Es kann vorkommen, dass der Market Sie gelegentlich auffordert, Ihre Installationsschlüssel zurückzusetzen. Das ist normal; folgen Sie einfach den Anweisungen.

- **Meine Jeedoms**: Hier werden alle Ihre Jeedoms aufgelistet
    - **Name**: Der Name, den Sie Ihrem Jeedom geben möchten (wird im Namen des Backups angezeigt, wenn Sie das Cloud-Backup-Abonnement haben).
    - **Status**: Zeigt den Status des betreffenden Jeedom an.
    - **Lokale/Remote-IP**: IP-Adresse dieses Jeedom-Geräts; wird in Jeedom konfiguriert. Wenn Sie nichts eingeben, wird die zuletzt bekannte IP-Adresse verwendet.
    - **DNS**: Hier können Sie den Namen Ihres DNS individuell anpassen.
    - **URL**: Listet die verschiedenen URLs für den Zugriff auf Jeedom auf.
    - **DNS-Server**: Zeigt Ihnen den DNS-Server an, mit dem Sie verbunden sind.
    - **DNS-Status**: Hier können Sie den DNS-Status einsehen.
    - **Erstellungsdatum**: Datum, an dem dieses Jeedom-Produkt in Ihrem Market-Konto erstellt wurde (zur Erinnerung: Dies geschieht automatisch, wenn Sie es mit dem Market verknüpfen).
    - **Letzte Aktualisierung**: Letzte Kommunikation zwischen Jeedom und dem Market.
    - **Hardware**: Name der Jeedom-Hardware.
    - **Version**: Die installierte Jeedom-Version.

> **Tipp**
>
> Vergessen Sie nicht, zu speichern.

## Meine Backups

Auf dieser Registerkarte können Sie die im Market verfügbaren Backups einsehen und eines davon herunterladen. Darunter finden Sie den Link, über den Sie ein 1-, 3-, 6- oder 12-monatiges Abonnement für die Cloud-Sicherung erwerben können.

## Meine SMS/Anrufe

Auf dieser Registerkarte können Sie Ihr SMS-/Anrufguthaben einsehen (verwendbar mit dem Plugin „Phone Market“). Darunter finden Sie verschiedene Optionen zum Kauf von zusätzlichem Guthaben.

## Meine Einkäufe/Angebote/Spenden

Hier finden Sie alle Ihre Einkäufe und können die erneute Zusendung der Rechnungs- oder Quittungs-E-Mail anfordern.

> **Wichtig**
>
> Wenn Sie ein offizielles Plugin kaufen, erhalten Sie eine Rechnung. Bei einem Plugin eines Drittanbieters erhalten Sie hingegen eine Quittung; eine Rechnung müssen Sie beim Entwickler anfordern.

Über diese Registerkarte können Sie auch einen Gutscheincode eingeben (beispielsweise einen Code für ein Plugin, den Ihnen der Entwickler möglicherweise übermittelt hat) und eine Spende tätigen.

## Meine Entwicklungen

Wenn Sie Entwickler sind, finden Sie hier eine Liste aller Ihrer Verkäufe in einem bestimmten Zeitraum, eine Liste Ihrer Auszahlungen sowie eine Übersicht über die Anzahl der Downloads, die Anzahl der Verkäufe …​
