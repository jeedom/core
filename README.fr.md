# Jeedom - La domotique innovante

Jeedom est un logiciel domotique open source, multi-protocoles et gratuit qui permet de centraliser et gérer vos objets connectés afin de rendre votre habitat réellement intelligent. Il ne nécessite pas d’accès à des serveurs externes pour fonctionner, garantissant ainsi une confidentialité complète.

Grâce aux scénarios intuitifs et simples à prendre en main, vous pouvez créer les automatismes qui vous ressemblent. Les widgets, les vues et les designs permettent de générer l'interface de votre choix facilement.

## Plugins

Jeedom s'articule autour du core, qui sert de noyau central fournissant les fonctions de base, et des plugins qui s'en servent pour proposer des fonctionnalités ciblées en fonction de votre matériel et de vos besoins.

Les plugins peuvent provenir de différentes sources *(officielles ou tiers)*, la principale étant le [Market Jeedom](https://market.jeedom.com). L'architecture décentralisée de Jeedom permet également de créer rapidement votre propre plugin dédié à vos exigences *(voir la section [Documentation générale - Développement de plugin](#documentation-générale))*.

## Documentation

La documentation complète est consultable à l'adresse suivante : https://doc.jeedom.com/home/fr_FR. Elle est composée de plusieurs rubriques regroupées sur ce site afin de fournir toutes les informations nécessaires au même endroit.

### Documentation générale

La documentation générale correspond aux éléments universels à connaître, non spécifiques au core ou aux plugins, tels que :

- [**Installation**](https://doc.jeedom.com/installation/fr_FR/) : guides pour installer Jeedom sur n'importe quel système Linux Debian 64 bits.
- [**Présentation**](https://doc.jeedom.com/presentation/fr_FR/) : présentation du logiciel et de ses principales fonctionnalités.
- [**Concepts**](https://doc.jeedom.com/concept/fr_FR/) : présentation des concepts d'utilisation et des possibilités offertes par Jeedom.
- [**Bêta-test et contributions**](https://doc.jeedom.com/contribute/fr_FR/beta) : procédure détaillée à destination des bêta-testeurs et contributeurs.
- [**Développement de plugin**](https://doc.jeedom.com/dev/fr_FR/) : guides relatifs aux différentes étapes de développement d'un plugin Jeedom.

### Documentation du core

Les documentations spécifiques au core Jeedom sont à la fois disponibles localement dans le dossier [docs/fr_FR](docs/fr_FR/) et dans les sections **Manuels d'utilisation** et **Manuels de configuration** du site de documentation.

#### Manuels d'utilisation

Chaque fonctionnalité Jeedom dispose de son propre manuel d'utilisation détaillé, par exemple :

- [**Changelog**](https://doc.jeedom.com/core/changelog) : le changelog recense les changements apportés par chaque version de Jeedom.
- [**Plugins**](https://doc.jeedom.com/core/plugin) : installer, configurer et bien utiliser les plugins Jeedom.
- [**Scénarios**](https://doc.jeedom.com/core/scenario) : détaille toutes les possibilités offertes pour la mise en place d'automatismes personnalisés.
- [**Widgets**](https://doc.jeedom.com/core/widgets) : permet de personnaliser l'affichage des commandes sur l'interface.
- [**FAQ**](https://doc.jeedom.com/core/faq) : réponses aux questions les plus couramment posées.

#### Manuels de configuration

Les guides de cette catégorie expliquent comment configurer Jeedom selon vos propres critères :

- [**Administration**](https://doc.jeedom.com/core/administration) : regroupe la plupart des paramètres configurables de Jeedom.
- [**Utilisateurs**](https://doc.jeedom.com/core/user) : permet de gérer les utilisateurs Jeedom et de configurer leurs accès et leurs droits.
- [**Préférences**](https://doc.jeedom.com/core/profils) : personnalisation de l'interface et de la sécurité de l'utilisateur courant.
- [**Personnalisation avancée**](https://doc.jeedom.com/core/custom) : personnalisation avancée de l'interface *(`CSS` et/ou `Javascript`)*.
- [**Sauvegardes**](https://doc.jeedom.com/core/backup) : configuration des sauvegardes Jeedom locales et distantes.

### Documentation des plugins

Chaque plugin Jeedom dispose de sa documentation et de son changelog, accessibles par sa catégorie *(Protocole domotique, Energie, Monitoring, Sécurité, Programmation, etc.)* dans les rubriques **Plugins officiels** concernant ceux développés par l'équipe Jeedom, ou **Plugins tiers** pour ceux issus de développeurs externes.
